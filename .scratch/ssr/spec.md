# 公開內容伺服器渲染

來源：使用者同意保留 Next.js 並實作先前建議的渲染分工。

- 第一階段：作品詳情改為 Server Component，初始 HTML 含標題、作者、作品、介紹與留言；按讚、留言保持瀏覽器端互動，成功後刷新伺服器資料。
- 第二階段：創作者、活動詳情與探索搜尋採用伺服器取得初始內容；委託詳情同為公開資料頁，套用相同方式。篩選、排序、分頁及活動投稿、追蹤等互動保留。
- 保留 Quill Delta 及既有 HTML/文字的格式，描述必須在 HTML 回應內，不依賴瀏覽器執行 Quill 才顯示。
- 公開詳情提供依資料產生的頁面標題與描述；不存在的資源回應 404，服務錯誤提供可見的重試入口。
- 伺服器向 C# API 取得資料，登入 Cookie 依請求傳遞；資料不跨使用者快取。權限、寫入及業務規則由 C# 負責。
- 會員中心、登入、訂單管理維持瀏覽器 React。首頁與活動列表不在本次範圍。
- 在既有 refactor/react 分支作業，不提交使用者 AGENTS.md 修改。每階段依 code-review 的 Standards / Spec 雙軸審查，修正後 commit。
- 驗證初始 HTML（停用 JavaScript 仍能讀主要內容）、metadata、404、Cookie 隔離及互動刷新。測試寫入使用隔離測試資料，不修改使用者 SQL Server。
